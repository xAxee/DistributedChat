Project overview

Distributed
Chat.

DistributedChat is a small real-time chat project built around multiple API instances. PostgreSQL stores the application state, while RabbitMQ distributes chat and presence events between backend instances.

Tech stack

Frontend

An Angular SPA for managing rooms, sending messages and displaying live connection updates.

  • Angular 21
  • TypeScript
  • RxJS
  • PrimeNG

Backend

A .NET API responsible for authentication, rooms, message history and SignalR connections.

  • .NET 10
  • ASP.NET Core
  • SignalR
  • Entity Framework Core

Data & messaging

PostgreSQL stores persistent application data. RabbitMQ forwards chat and presence events between API instances.

  • PostgreSQL
  • RabbitMQ

Infrastructure

The full application runs locally in Docker containers behind Nginx, with builds and tests handled by GitHub Actions.

  • Docker Compose
  • Nginx
  • GitHub Actions
